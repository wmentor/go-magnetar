# Contributing

Before opening an issue:

- 🔍 Search existing issues first
- 📖 Check the [documentation](https://github.com/wmentor/go-magnetar/tree/master/docs)
- 🐛 For bugs: use the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.md)
- ✨ For features: use the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.md)

## Issue Templates

| Template | Description |
|----------|-------------|
| 🐛 [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) | Report something that isn't working |
| ✨ [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) | Suggest an idea for this project |
